# Prabhu Trade Union Website

A modern and responsive website developed for **Prabhu Trade Union** to provide information about the organization, workers' rights, welfare activities, notices, and other important union information.

## 🚀 Project Overview

The Prabhu Trade Union website is designed to provide a professional and easy-to-use online platform for union members and visitors.

The project focuses on a clean user interface, responsive design, smooth interactions, and easy access to important information.

## ✨ Features

* 🏠 Modern homepage
* ⚖️ Rights and Welfare section
* 📢 Notices and announcements
* 🖼️ Gallery
* 👥 Union information
* 🔐 Admin dashboard
* 📱 Responsive design
* ✨ Smooth hover and button animations
* 🎨 Modern and user-friendly interface

## 🛠️ Technologies Used

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/prabhu-trade-union-website.git
```

Move into the project directory:

```bash
cd prabhu-trade-union-website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
